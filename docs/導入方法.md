# Sisho の導入

Claude（または ChatGPT）に Sisho を連携し、MTG のカードデータや公式ルールを引けるようにする手順です。
※画面のボタン名や配置は、claude.ai や ChatGPT のアップデートによって多少変わることがあります。

## 用意するもの

1. Claude（claude.ai）のアカウント
   無料プランでも利用可能です（カスタムコネクタ枠を 1 つ使用します）。
   ChatGPT で使う場合は、有料プラン（Plus・Pro など）のアカウントが必要です（下の「ChatGPT」）。
2. Sisho の接続 URL
   発行ページ（ https://sisho.tailf8ef32.ts.net/issue ）を開き、［発行する］ボタンを押して自分用の URL を取得してください。
   ※URL は合言葉（秘密鍵）と同じです。他人には見せないようご注意ください。紛失した場合はいつでも再発行できます。

## 接続手順

お使いのツールに合わせて設定してください。

### claude.ai（ブラウザ・アプリ）

1. ブラウザで claude.ai を開き、左下の自分のアカウント名をクリックして［設定］→［コネクタ］を開きます。
2. 画面右上にある［追加］（またはカスタムコネクタの追加）を押します。
3. 名前に `sisho`（任意の名前で構いません）と入力し、URL に取得した接続 URL を貼り付けます。
   ※「Advanced settings」（OAuth の欄）は触らずに、そのまま追加してください。
4. ログインや許可の画面は出ず、URL を登録するだけで接続が完了します。
5. 新しいチャット画面を開き、コネクタのアイコンで `sisho` が有効になっていることを確認してください。

※ブラウザ版で一度追加すれば、Claude デスクトップアプリやスマートフォンの Claude アプリでもそのまま利用できます。

### ChatGPT（ブラウザ）

ChatGPT でも使えます。ただし**有料プラン（Plus・Pro・Business・Enterprise・Education）が必要**で、設定はブラウザ版の ChatGPT から行います（無料プランでは使えません・2026 年 10 月時点の OpenAI の案内）。

1. ブラウザで ChatGPT を開き、［設定（Settings）］→［セキュリティとログイン（Security and login）］で「開発者モード（Developer mode）」をオンにします。
2. 画面左のサイドバーにある［プラグイン］を押し、右上の黒い［追加］から「MCP アプリを作成」を選びます。
3. 出てきた画面の「接続タイプ」の欄に、取得した接続 URL を貼り付けます。名前と説明は何でも構いません（例: `sisho`）。「理解したうえで続けます」にチェックを入れて作成します。
4. 新しいチャットを開き、そのまま MTG の質問をして、sisho が呼ばれることを確かめてください。

### Claude Code（CLI）

Claude Code をお使いの場合は、ターミナルで以下のコマンドを実行してください（`<接続URL>` に取得した URL を入れます）。

```bash
claude mcp add --transport http sisho <接続URL>
```

※Claude Code 向けに、回答前にカード名を機械検査する仕組み（Stop フック）も用意しています。詳しくは [../hooks/README.md](../hooks/README.md) をご覧ください。

### Antigravity（アプリ / IDE）

Antigravity をお使いの場合は、MCP 設定画面からサーバーを追加します。

1. 設定から MCP サーバーの追加画面を開きます。
2. サーバー名に `sisho`、URL に取得した接続 URL を入力して登録します。

## 使い方

コネクタを追加したら、チャットでそのまま質問できます。

（質問例）
- 「Lightning Bolt の日本語名と、本文を教えて」
  → 《稲妻/Lightning Bolt》 のように、《日本語名/英語名》の正式名称付きで回答されます。
- 「統率者戦で Sol Ring と一緒に入りやすいカードを 5 枚教えて」
  → 《太陽の指輪/Sol Ring》 と同じデッキに入っている割合の高いカードを、実際の大会デッキ集計から返します。
- 「60 枚のデッキに 4 枚入れたカードを、初手 7 枚で 1 枚以上引く確率は？」
  → 前提（先手/後手、マリガン回数）と計算式を添えて正確な数字を返します（AI に暗算させません）。
- 「Counterspell の公式裁定を教えて」
  → 《対抗呪文/Counterspell》 の裁定を、公式ルールの文面で返します。
- 「飛行のルールを総合ルールから引いて」
  → 条番号付きの正式な条文を引用して答えます。

## 答えの見方

### カード名の完成形

日本語で MTG を語るとき、AI はカード名を自分で翻訳してしまうことがあります（例: Stifle を「スティフル」と訳す。正しくは《もみ消し/Stifle》）。
Sisho はカード情報を扱うツールの返り値に《日本語名/英語名》という完成形の文字列を載せています。AI がその文字列を使って回答文を作るので、自分で訳した名前が出にくくなります（それでも間違えることはあるので、下の「回答の検証」も使ってください）。日本語版が無いカードは英語名のみ（日本語版なし）を返します。

- 回答の検証: Claude がカード名を略したり不確かな回答をした場合は、「確かめて」と頼むと、データベースと突き合わせて検証・修正してくれます。
- リミテッドのデータ: ドラフトの勝率やピック順は 17Lands の公開データの集計に基づきます（回答に出典が明記されます）。

## うまくいかないとき

- **「使いすぎ」「429」と出る場合**: 1 分ほどお待ちください。利用回数の上限による一時的な制限です。
- **「つながらない」「見つからない」と出る場合**: 接続 URL を正しく貼り直してください。それでも解決しない場合は URL が失効している可能性があるため、発行ページで再取得してください。
- **AI が「使えない」「ツールが見つからない」と言う場合**: まず**新しいチャットを開いて**質問し直してみてください（過去の会話や古いツール一覧を引きずっていることが多く、開き直すだけで解決することがあります）。それでも改善しない場合は、ツールの有効化設定を確認するか、コネクタ設定で更新（再接続・CLI なら再起動）してください。
- **動作確認をしたい場合**: チャットで「mtg_rag_health を呼んで」と頼んでみてください。データベースとの接続状況や、データの件数・鮮度を確認できます。

## 知っておいてほしいこと

- **ログの記録**: AI がサーバーに送信した問い合わせ内容（検索語やカード名など）は、障害対応および品質改善のためにサーバー側にログとして記録されます（約 5 週間で消去・第三者への提供は行いません）。
- **サービスの稼働**: 公開サーバーは Tailscale Funnel（beta）を利用しているため、帯域制限等により一時的に停止する場合があります。
- **免責事項**: AI は間違えることがあります。その他、Sisho を利用したことによるいかなる不利益についても、作者は一切の責任を負いかねます。
