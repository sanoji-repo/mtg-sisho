# Sishoの導入

Claude に Sisho を連携し、MTG のカードデータや公式ルールを引けるようにする手順です。
※画面のボタン名や配置は、claude.ai のアップデートによって多少変わることがあります。

## 用意するもの

1. Claude（claude.ai）のアカウント
   無料プランでも利用可能です（カスタムコネクタ枠を 1 つ使用します）。
2. Sisho の接続 URL
   発行ページ（ https://sisho.tailf8ef32.ts.net/issue ）を開き、ボタンを押して自分用の URL を取得してください。
   ※URL は合言葉（秘密鍵）と同じです。他人には見せないようご注意ください。紛失した場合はいつでも再発行できます。

## つなぐ（ブラウザ）

1. ブラウザで claude.ai を開き、左下の自分のアカウント名をクリックして［設定］→［コネクタ］を開きます。
2. 画面右上にある［追加］（またはカスタムコネクタの追加）を押します。
3. 名前に `sisho`（任意の名前で構いません）と入力し、URL に取得した接続 URL を貼り付けます。
   ※「Advanced settings」（OAuth の欄）は触らずに、そのまま追加してください。
4. ログインや許可の画面は出ず、URL を登録するだけで接続が完了します。
5. 新しいチャット画面を開き、コネクタのアイコンで `sisho` が有効になっていることを確認してください。

※スマートフォンの Claude アプリでも、同様に［設定］→［コネクタ］から追加できます。

## つなぐ（CLI）

Claude Code をお使いの場合は、ターミナルで以下のコマンドを実行してください（`<接続URL>` に取得した URL を入れます）。

```bash
claude mcp add --transport http sisho <接続URL>
```

※Claude Code 向けに、回答前にカード名を機械検査する仕組み（Stop フック）も用意しています。詳しくは [../hooks/README.md](../hooks/README.md) をご覧ください。

## 使い方

コネクタを追加したら、チャットでそのまま質問できます。

1. 「Lightning Bolt の日本語名と、本文を教えて」
   → 《稲妻/Lightning Bolt》 のように、《日本語名/英語名》の正式名称付きで回答されます。
2. 「統率者戦で Sol Ring と一緒に入りやすいカードを 5 枚教えて」
   → 《太陽の指輪/Sol Ring》 と同じデッキに入っている割合の高いカードを、実際の大会デッキ集計から返します。
3. 「60 枚のデッキに 4 枚入れたカードを、初手 7 枚で 1 枚以上引く確率は？」
   → 前提（先手/後手、マリガン回数）と計算式を添えて正確な数字を返します（AI に暗算させません）。
4. 「Counterspell の公式裁定を教えて」
   → 《対抗呪文/Counterspell》 の裁定を、公式ルールの文面で返します。
5. 「飛行のルールを総合ルールから引いて」
   → 条番号付きの正式な条文を引用して答えます。

## 答えの見方

### カード名の完成形

日本語で MTG を語るとき、AI はカード名を自分で翻訳してしまうことがあります（例: Stifle を「スティフル」と訳す。正しくは《もみ消し/Stifle》）。
Sisho はカード情報を扱うツールの返り値に《日本語名/英語名》という完成形の文字列を載せています。AI はその文字列を使って回答文を作成するため、自分で勝手に訳さず正式な名称で出力されます。日本語版が無いカードは英語名のみ（日本語版無し）を返します。

- 回答の検証: Claude がカード名を略したり不確かな回答をした場合は、「確かめて」と頼むと、データベースと突き合わせて検証・修正してくれます。
- リミテッドのデータ: ドラフトの勝率やピック順は 17Lands の公開データの集計に基づきます（回答に出典が明記されます）。

## うまくいかないとき

- 「使いすぎ」「429」と出る場合: 1 分ほどお待ちください。1 人あたりの利用回数に上限が設定されています。
- つながらない・「見つからない」と出る場合: URL を正しく貼り直してください。それでも解決しない場合は URL が失効している可能性があるため、発行ページで再取得してください。
- Claude が「Sisho を使えない」と言う場合: チャット画面のツール一覧で `sisho` が有効になっているか確認してください。新しい会話（チャット）を開き直すと改善することが多いです。
- 動作確認をしたい場合: チャットで「mtg_rag_health を呼んで」と頼んでください。データベースとの接続状況や、データの件数・鮮度が返ってきます。

## 知っておいてほしいこと

- AI がサーバーに送信した問い合わせ内容（検索語やカード名など）は、障害対応および品質改善のためにサーバー側にログとして記録されます（第三者への提供は行いません）。
- 公開サーバーは Tailscale Funnel（beta）を利用しているため、帯域制限等により一時的に停止する場合があります。
- AI は間違えることがあります。その他、本 MCP を利用したことによるいかなる不利益についても、作者は一切の責任を負いかねます。
- 個人運営による無保証のサービスです。不具合報告やご要望は GitHub の Issues までお寄せください。
