# はじめての Sisho

Claude に Sisho をつないで、最初の問いを投げるまでの手順。読み手は「AI に MTG のことを聞きたいプレイヤー」。技術の話はしない。
自分でサーバーを立てたい人は [SETUP.md](./SETUP.md) へ。

初稿 2026-09-07。画面の文言（ボタンの名前など）は claude.ai の版で変わることがある。

## Sisho は何をしてくれるか

Claude は MTG のカード名を自分で翻訳してしまうことがある（例: 英語名だけ知っているカードに、存在しない日本語名を付ける）。
Sisho をつなぐと、Claude はカードの正式な日本語名・本文・総合ルールの条文・公式裁定・実際の大会デッキの統計を、記憶ではなくデータベースから引いて答える。
数字を出す道具（確率の計算・採用率・ドラフトの勝率）も入っている。

## 用意するもの

1. claude.ai のアカウント。無料プランでも使える（カスタムコネクタは 1 つまで。Sisho をつなぐとその 1 枠を使う）。
2. Sisho の接続 URL。発行ページ https://sisho.tailf8ef32.ts.net/issue のボタンを押すと、自分用の URL が出る。
   URL は合言葉と同じ。人に見せない。無くしたら取り直せる。

## つなぐ（claude.ai）

1. claude.ai を開き、設定（Settings）→ コネクタ（Connectors）を開く。
2. 「カスタムコネクタを追加（Add custom connector）」を押す。
3. 名前に `sisho`、URL に受け取った接続 URL を貼る。「Advanced settings」（OAuth の欄）は触らない。追加する。
4. ログイン画面や許可の画面は出ない。URL を入れるだけでつながる。
5. 新しい会話を開き、道具の一覧（コネクタのアイコン）で `sisho` が有効になっているのを確かめる。

スマホのアプリでも同じ項目（設定 → コネクタ）から追加できる。

## つなぐ（Claude Code）

ターミナルで次を打つ。`<接続URL>` は受け取った URL。

```
claude mcp add --transport http sisho <接続URL>
```

Claude Code には、答える前にカード名を機械で検査させる仕組み（Stop フック）も用意している。使いたい人は [../hooks/README.md](../hooks/README.md)。

## 最初の問い（例）

そのまま貼って試せる。

1. 「Lightning Bolt の日本語名と、本文を教えて」
   → 《稲妻/Lightning Bolt》 のように、《日本語名/英語名》の形で返る。
2. 「統率者戦で Sol Ring と一緒に入りやすいカードを 5 枚」
   → 《太陽の指輪/Sol Ring》 と同じデッキに入っている割合の高いカードを、実際のデッキの集計から返す。
3. 「60 枚のデッキに 4 枚入れたカードを、初手 7 枚で 1 枚以上引く確率は？」
   → 式と前提（先手か後手か・マリガンの回数）を添えて数字を返す。Claude に暗算させない。
4. 「Counterspell の公式裁定を教えて」
   → 《対抗呪文/Counterspell》 の裁定を、公式の文面で返す。
5. 「飛行のルールを総合ルールから引いて」
   → 条番号つきの条文で返る。

## 答えの見方

- カード名は 《日本語名/英語名》 の形で出る。この形なら、データベースにある正式名。
- 「英語名（日本語版なし）」と出たら、そのカードには日本語版が存在しない。Claude が勝手に訳した名前ではない。
- Claude がカード名を略したり自分の訳を書いたりしたら、「verify_answer で確かめて」と頼むと、データベースと突き合わせて直した文を返す。
- ドラフト（リミテッド）の勝率やピック順は 17Lands の公開データの集計。答えに「17Lands」と出典が付く。

## うまくいかないとき

- 「使いすぎ」「429」と出る: 1 分待つ。一人当たりの回数に上限がある。
- つながらない・「見つからない」: URL を貼り直す。それでも駄目なら URL が止められている可能性がある。発行ページで取り直す。
- Claude が「Sisho を使えない」と言う: 会話の道具の一覧で `sisho` が有効か見る。新しい会話を開くと直ることが多い。
- 動いているか確かめたい: 「mtg_rag_health を呼んで」と頼む。データベースとの疎通と、データの件数・鮮度が返る。

## 知っておいてほしいこと

- 送った問いの中身（検索語やカード名など）は、障害対応と品質改善のためサーバー側に記録する。第三者には渡さない。
- 答えの文章を作るのは Claude。Sisho が返すのはデータベースの値で、その値は記録から確認できる。
- 公開口は Tailscale Funnel（beta）で、帯域の上限がある。止まることもある。
- 無保証の個人運営。止まることもある。困ったら GitHub の Issues へ。
