## Q1「モダンのスケープシフトってヴァラクートとアミュレットタイタンどっちが多い？」

DB 裏取り（Fable）: Modern × Scapeshift 採用＝Amulet Titan 69／未分類 6／Scapeshift 4／その他 1。3 本とも道具を引いてから回答
（search→describe→SQL・Opus は共起も）。所要: medium 20 秒（7 ターン）／xhigh 26 秒（6）／Opus low 37 秒（8）。

### 本人採点（原文）
- **Sonnet medium**: 間違いはないが情報量が少ない。あまりに情報量がなさすぎるので**減点**。
- **Sonnet xhigh**: 共起データで「原始のタイタンが 73 デッキ」と書いてあるが、**ヴァラクートにも原始のタイタンが入っているので基準にならない**（根拠の取り違え）。
- **Opus low**: アミュレットタイタンの中のサブフィニッシュ手段としてのヴァラクートに触れているのは**偉い**。ただし日本語が少し怪しい（「原始のタイタンで持ってくる土地基盤等を含む土地サーチ」は意味を捉えにくい）。

### 採点から見えた物差し（規約の芽・本人の言葉から起こした仮置き）
1. 正確さ（数字が DB と合うか・根拠が問いの判別に効くか）——xhigh の共起根拠は「正しい数字だが判別に効かない」型の減点
2. 情報量（問いの裏にある「なぜ」まで触れるか）——medium は正しいが薄い
3. 日本語の明瞭さ——Opus は内容は良いが文が読みにくい
