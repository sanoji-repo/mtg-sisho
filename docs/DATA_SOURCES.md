## 共通の礼儀

- 取得済みは必ずスキップし、同じコマンドを毎晩打っても新規分だけ取りに行く（差分運用がコマンド不変で成立する）。
- 失敗の再試行は短い回数で諦め、次の便で拾い直す。相手のサーバーを叩き続けない。
- スクレイプ対象の利用規約は、取得を始める前に検査し、結果をここに書く。未検査のものは未検査と書く。

## Commander Spellbook（2026-09-04・都度照会）

- 何を: コンボの検索（`find_combos`）。公開 REST API `find-my-combos` を利用者の問いごとに呼ぶ。
- 取り込み: しない（データ自体のライセンスが明文化されていないため、DB に保存・再配布しない）。返り値には出典「Commander Spellbook」と各コンボの URL、前提の原文を添える。
- 注意: bracket タグと結果タグは参考扱い（正確性に欠ける実例が公開されている）。
